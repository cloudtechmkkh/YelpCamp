📌 プロジェクト概要
YelpCamp は、キャンプ場のレビュー投稿サイトをフルスタックで構築する学習プロジェクトです。
ユーザー登録、ログイン、キャンプ場の CRUD、レビュー投稿、地図表示など、
Web アプリケーションに必要な機能を一通り実装しています。
このプロジェクトを通じて、
認証・データベース・REST API・テンプレートエンジン・デプロイ など、
実務に近いフローを体系的に学びました。

🛠 使用技術
バックエンド
- Node.js / Express
- MongoDB / Mongoose
- Passport.js（認証）
- Joi（バリデーション）
フロントエンド
- EJS（テンプレートエンジン）
- Bootstrap
- Mapbox（地図表示）
その他
- Cloudinary（画像アップロード）
- Heroku / Render（デプロイ）

🎯 学んだこと・意識したポイント
1. RESTful 設計の理解
- /campgrounds
- /campgrounds/:id
- /campgrounds/:id/reviews
など、リソースごとにルーティングを整理し、
HTTP メソッドと URL 設計の関係を理解しました。

2. 認証・認可の実装
- Passport.js を使ったログイン機能
- ログインしていないユーザーのアクセス制限
- 投稿者本人のみ編集・削除可能にする認可処理
実務でも必須の「誰が何をできるか」の制御を学びました。

3. スキーマ設計とバリデーション
- Mongoose でのスキーマ定義
- Joi を使ったサーバーサイドバリデーション
- フロントとバックの両方で入力チェックを実装
データの整合性を保つ重要性を理解しました。

4. 画像アップロードと外部サービス連携
- Cloudinary を使った画像アップロード
- 画像削除時の Cloudinary 側の同期処理
外部 API を扱う経験ができました。

5. 地図表示（Mapbox）
- キャンプ場の位置情報を地図上に表示
- ピンの表示、ズーム、ポップアップなどの UI 実装
地図 API の扱い方を学び、
フロントとバックのデータ連携を理解しました。

💡 工夫した点
- エラーハンドリングをミドルウェアで共通化
- 非同期処理を async/await で統一
- セッション管理を安全に行うための設定（secret, cookie options）
- テンプレートの共通化（partials）で保守性を向上
- レスポンシブ対応で UI を改善
